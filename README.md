同一个动态口令被用了三次都通过，重放窗口形同虚设，计数器还往回退了一格：验证通过后计数器必须单调推进，同一口令不得重复使用，允许的前瞻窗口有限且必须记录已用计数，计数器回退必须拒绝，窗口内的每个计数只能消费一次，批量验证时各用户状态互相独立。任一计数值最多被成功消费一次，计数器只增不减。

运行公开测试：python -m pytest tests -q

状态由当前计数值与已用计数集合组成。拒绝时必须显式报错，不得静默沿用旧状态。
